## Description of Changes

<!-- user-editable-section-start -->
- Add the `get-risk-label-name` action.
  - This translates a single risk level to a risk label name, so we can then add the risk label to pull requests.
- Add the `add-risk-label` action.
  - This takes a risk label and adds it to the pull request, provided that it is one of the allowed risk labels and is not already present.

## Additional Notes

- The logic for this actually does already exist in the `github-actions` repository, but it's in Bash and it sucks!
- I would now like to take the time to immortalise the horror before we replace it for good.

```bash
PULL_REQUEST_LABELS="$(gh pr view "$PULL_REQUEST_NUMBER" --json labels)"

mapfile -t EXISTING_RISK_LABELS < <(
jq -r '
    .labels[].name |
    select(
    . == "low risk" or
    . == "medium risk" or
    . == "high risk"
    )
' <<< "$PULL_REQUEST_LABELS"
)

if [[ ${#EXISTING_RISK_LABELS[@]} -gt 0 ]]; then
if [[ ${#EXISTING_RISK_LABELS[@]} -eq 1 && ${#EXISTING_RISK_LABELS[0]} == $RISK_LABEL ]]; then
    echo "Risk label already added."
    exit 0
fi

for LABEL in "${EXISTING_RISK_LABELS[@]}"; do
    gh pr edit "$PULL_REQUEST_NUMBER" --remove-label "$LABEL"
done
fi

gh pr edit "$PULL_REQUEST_NUMBER" --add-label "$RISK_LABEL"
```
